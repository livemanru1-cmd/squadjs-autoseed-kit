# Переносимый комплект автосида для SquadJS

Комплект позволяет владельцу серверов Squad:

- опубликовать из SquadJS безопасный снимок состояния сервера;
- показать несколько серверов на статической странице GitHub Pages;
- выбрать сервер для сида по заданному приоритету;
- получить у экспортёра одноразовую ссылку подключения Steam без передачи ключа в браузер.

В комплект входят плагин `AutoseedExporter`, его две служебные зависимости, пример настройки SquadJS и минимальная страница без сборщика.

## Быстрый запуск

Требуется совместимая сборка SquadJS на Node.js 20 или новее и внешний HTTPS-адрес, направленный только на экспортёр.

1. Установите файлы в свой checkout SquadJS:

   ```bash
   bash scripts/install.sh ../SquadJS
   ```

   Если там уже есть отличающиеся файлы, скрипт остановится. Сначала сравните изменения; осознанная замена выполняется с `--force`.

2. Добавьте в `connectors` ключ SquadBrowser и блок из [примера плагина](examples/squadjs-plugin.json). Значения `${...}` должны подставляться вашим способом запуска SquadJS.

3. Опубликуйте экспортёр через HTTPS и разрешите точный источник своей страницы:

   ```json
   "corsOrigins": ["https://OWNER.github.io"]
   ```

   Не публикуйте RCON, базу данных или весь административный интерфейс SquadJS. Наружу нужны только маршруты под `pathPrefix`.

4. Проверьте:

   ```bash
   curl --fail https://exporter.example.org/v1/autoseed/readyz
   curl --fail https://exporter.example.org/v1/autoseed/snapshot
   ```

5. Отредактируйте [site/config.js](site/config.js): добавьте адреса `snapshot` и `join-link`, код, название и числовой приоритет каждого сервера.

6. В настройках репозитория выберите Pages → Source → GitHub Actions. Встроенный процесс опубликует каталог `site` после слияния в `main`.

Подробности параметров находятся в [docs/variables.md](docs/variables.md), типовые ошибки — в [docs/troubleshooting.md](docs/troubleshooting.md).

## Как выбирается сервер

Страница рассматривает только серверы, у которых одновременно:

- экспортёр вернул свежий снимок;
- `online: true`;
- `isSeedCandidate: true`;
- сервер не заполнен.

Из них выбирается наименьший `priority`. Например, порядок `Mix → Spec Ops → Invasion` задаётся значениями `10`, `20`, `30`. При одинаковом приоритете выше ставится сервер с большим числом игроков, затем сравнивается код.

Кнопка подключения не содержит ключ SquadBrowser: браузер вызывает `join-link` вашего экспортёра, а тот обращается к SquadBrowser на стороне SquadJS.

## Граница безопасности

- В `site` не должно быть токенов, RCON-паролей, адресов баз данных и других секретов.
- Ключ SquadBrowser хранится только в секретах процесса SquadJS.
- Используйте точный список `corsOrigins`, HTTPS и ограничение частоты запросов.
- Публичный снимок не содержит SteamID/EOSID. Не добавляйте их в страницу вручную.
- Эта поставка не отключает проверку TLS при ошибке сертификата.

## Совместимость и обновление

Исходная версия и отличия зафиксированы в [SOURCE.md](SOURCE.md). Перед обновлением сначала синхронизируйте `overlay`, прогоните проверки и только затем выпускайте страницу. Автоматически копировать неизвестную новую версию плагина в рабочий SquadJS не следует.
